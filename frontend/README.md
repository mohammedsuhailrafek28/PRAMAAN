# Pramaan Frontend MVP

Pramaan is India's consent-based business trust infrastructure for MSMEs. This frontend is connected to the rule-based backend at `http://localhost:4000/api`; it does not use LLMs, blockchain, lending, marketplace, or scoring services.

## Setup

```bash
npm install
npm run build
npm run dev
```

Set `VITE_API_URL` when the backend is hosted elsewhere. The default is `http://localhost:4000/api`.

## Local URLs

- Frontend: `http://localhost:5173`
- Backend health: `http://localhost:4000/api/health`
- Backend API docs: `http://localhost:4000/api/docs`

## Demo flow

Use the seeded backend accounts:

- MSME: `msme@pramaan.demo` / `password123`
- Buyer: `buyer@pramaan.demo` / `password123`
- Bank: `bank@pramaan.demo` / `password123`

1. Log in as MSME and complete Business Verification. The selected evidence tiles create real multipart PDF uploads, then the backend runs its deterministic cross-check.
2. Generate the Business Trust Passport.
3. Use **Switch demo role** to log in as Buyer, search the MSME GSTIN, and request selected fields.
4. Switch to MSME, approve a subset of fields for a duration, then switch to Buyer and open the filtered Trust View.
5. Revoke the consent as MSME. The buyer then receives the backend's `CONSENT_REVOKED` response and the view is blocked.
6. Review the audit timeline and notifications generated by the backend.

The switcher performs real login calls for each seeded identity. It is only a convenience for the demo; authorization still comes from the backend JWT.

## Architecture

- `src/services/api.ts` is the single HTTP adapter. It owns the API base URL, JWT header, backend-to-UI field mapping, multipart uploads, and error normalization.
- `src/store/` contains Zustand state for authenticated identity and the business/consent lifecycle.
- `src/pages/` and `src/components/` provide the MSME, buyer, bank, passport, consent, audit, and cinematic landing experiences.

The backend remains the source of truth. The old mock fixtures are retained only as unused development reference data and are not read by the running application.
